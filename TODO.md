# ToDo — пользовательский интерфейс Solanero

## Product-style presentation
- [x] Главная страница выглядит как готовый Solanero user dashboard: доступны market overview, Phantom-connect control, product navigation и понятный доступ к SOL/XMR section.
- [x] Удалены видимые метки «Concept», «Demo», «Early concept» и «Not live» в заголовке сайта, кнопках, навигации, open-graph и основным promotional текстом; вместо них использованы названия пользовательских функций.

## Активные интерфейсные функции
- [x] По добровольному ручному нажатию пользователь может подключить установленное Phantom extension для отображения сокращённого public Solana address; это не подключает автоматически, не читает баланс и не вызывает RPC, approval или подпись.
- [x] Сайт показывает онлайн-графики SOL/USD, BTC/USD и XMR/USD за 1D, 7D и 30D с CoinGecko attribution, sample time, понятными error/loading states, memory cache и 429 backoff.
- [x] Пошаговый product-flow guide работает как UI-переключатель последовательности, но явно говорит о только информационном характере прохождения, не использует адрес/кошелёк и не отправляет транзакций.

## Невыпущенные функции, условия доступности и точность
- [x] SOL/XMR liquidity access остаётся недоступным. Нет включённых deposit/swap/withdraw controls; интерфейс не получает и не переводит активы.
- [x] Контент не утверждает, что Monero криптография или ZK-функции уже интегрированы; дизайн и экономические параметры $SLNR корректно описаны как отсутствующие/неподтверждённые условия релиза, а не как действующий продукт.
- [x] Сайт не выдумывает token page, mint/contract/program address, конкретную доходность, executable quote, audit, privacy guarantee или дату запуска.
- [x] Пользовательская мобильная/desktop-адаптация, клавиатурная навигация, reduced-motion и чёткие статусы сохранены.
